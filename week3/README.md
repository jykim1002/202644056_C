3주차 정리 

(조건문)
if
if-else
중첩 if문의 사용
 • 복잡한 조건 처리
 • 순차적 평가
 • 구조의 복잡성
 • 분기의 다양성

(다중 선택문)
switch case문
 • 하나의 변수나 표현식의 값에 다라 여러 가지 선택 사항 중 하나를 선택하여 실행할 때 사용
 • 값이나 상태에 따라 각기 다른 코드 블록을 실행해야 할 때 유용

(반복문)
while
• 주어진 조건이 참인 동안 특정 코드 블록을 반복적으로 실행하는 제어 명령문
• 반복문을 시작하기 전에 조건을 검사하는 수행 전 검사 루프 구조로 초깃값 설정
• 조건식을 선언하여 반복 여부 결정
• 코드 블록 내에 증감식을 작성하여 반복 횟수를 제어

do~while 문
• 주어진 조건이 참인 동안 블록 내부의 코드를 반복적으로 실행하는 제어 명령문
• while 문과 달리 do~while 문에 진입하면 무조건 블록 내부의 수행 코드를 실행

for문 (파이썬과 다르게 변수 선언 중요)
• 주어진 조건이 참인 동안 특정 코드 블록을 반복적으로 실행하는 반복 제어문
• 반복을 위한 초깃값, 조건식 평가, 반복을 제어하는 증감식 연산이 한 줄에 모두
포함된 간결한 문법

• 초기화: 반복 횟수를 저장할 변수를 선언하거나 초기화하는 단계
• 조건식: 결과가 참이면 중괄호 안의 수행 코드 블록 실행, 거짓이면 반복 종료
• 증감식: 반복문의 변숫값을 증가시키거나 감소시킬 때 사용
